# Employee Information Management System

A simple CRUD web app: add, view, edit, and delete employee records online.

**Tech:** HTML, CSS, JavaScript, PHP, MySQLi, MySQL, GitHub, InfinityFree

## Files
- `index.php` – Read (list + search)
- `create.php` – Create
- `edit.php` – Update
- `delete.php` – Delete
- `config.php` – MySQLi database connection
- `database.sql` – table structure
- `style.css`, `script.js` – design and interaction
